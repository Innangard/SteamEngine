Content For This Game Browse all (1) We Are Gum - Game Talent Showcase Edition $4.99 $4.99 Add all DLC to Cart View Community Hub About This Game A puzzle game about goofy alien bubble gum trying to find their way home. They move together because they're aliens. They stick to things because they're bubble gum. They're silly and goofy because they're alien bubble gum! Don't question the science. Game Features: A Short and Sweet 5-6 Hours about Alien Bubble Gum trying to find their way home. All Gums Move Together: Every Gum moves at the same time, whether you're ready or not! Precision? Coordination? Chaos? Yes. 60+ hand-crafted puzzles: Each level design to make you think, teach you each mechanics and help you navigate through the game difficulties. Stick to Literally Everything: Walls, blocks and more blocks. These Gums are so sticky, it's almost a problem (but that's kinda the whole point). Push It, Then Stick It: You can shove stones like classic Sokoban, but don’t push too hard... You might just glue yourself to them. Built-in Hint System: Guidance to help untangle tricky movement paths whenever you need a boost. Accessibilities Features Unlimited Undo and Restart Game is fully playable with keyboard or gamepad. No mouse input is required. No time critical inputs are required. No simultaneous key presses are required. We Are Gum was originally created during Global Game Jam 2025. The game later won the Game Talent Showcase 2025 and the Best Student Game Award at BIDC 2025, while also being named a finalist for the BIDC Rising Star Award. The game was made using Unity 6.
