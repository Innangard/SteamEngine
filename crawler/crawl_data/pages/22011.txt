A humanidade teve uma boa vida, mas chegou a altura de reclamares o que é teu. Mergulha num jogo roguelike de construção de baralhos à base de dados onde as tuas decisões táticas, não a sorte, determinam o destino do planeta. Constrói a tua própria invasão Constrói uma força alienígena crescente numa grelha por turnos, onde cada peça é importante. Em cada turno, podes adquirir diferentes unidades, artefactos, "budges" e "chrono". Dispõe os teus invasores de forma estratégica na grelha para aumentares o teu potencial de pontuação. Manipula os dados Aqui, os dados não são um jogo de azar, são a tua ferramenta mais poderosa. Com "Chrono" podes voltar a rolar estrategicamente os teus dados e a reabastecer a loja para recrutares as unidades mais importantes. Podes transformar um mau lançamento numa reação em cadeia imparável. Usa "budge" para manipulares os dados lançados, de modo a construíres a combinação exata desejada. Até podes alinhar os teus dados em pares, trios e quadras para gerares combinações devastadoras. Sê o comandante Cada comandante tem a sua própria abordagem estratégica, sinergias especializadas e possibilidades de aumento de XP, desbloqueando novas formas de dominar. Cada um está equipado com benefícios únicos e artefactos, para que cada lançamento te dê novas formas de lançares o teu nível de ataque para a estratosfera. A Terra não será destruída sem dar luta. Tem cuidado, os pilotos lendários de StarVaders irão aparecer para proteger o planeta, cada um deles armado com as suas competências únicas, concebidas para perturbar a tua invasão. Quebra o jogo Faz experiências com sinergias absurdas e leva ao limite os sistemas do jogo. Descobre uma combinação absurda que lança a tua pontuação para a órbita e leva a melhor sobre os pilotos.
