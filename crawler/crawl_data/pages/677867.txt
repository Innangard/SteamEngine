This product includes 3 different puzzles. Features: - Native Windows Forms interface. - The goal of each of these errative puzzle games is to set all the flags and then perform the final control activation, typically a scrollbar movement. - All the flags are hinted in a message box which is shown by pressing a certain button in a previously unknown place. - Every game has a way to close itself unexpectedly - this is a gameover and you have to restart it manually. - Some controls reset your progress, but sometimes it is necessary to advance. - In the end, the game also closes itself. There is only one way to finish each puzzle.
