Learn more What the developers have to say: Why Early Access? “The game was part of a challenge to finish a game in 4 months. This timeframe is over and now I want to sell the game on Steam. I feel the need to tag the game as "Early Access" because I plan on redoing the entire map from scratch. The game is bound to change a lot in the process and it would be unfair to sell the game as is without warning people.” Approximately how long will this game be in Early Access? “Less than a year.” How is the full version planned to differ from the Early Access version? “I want to add (at minimum) these following features: - New open-world map made from scratch (the current world is a placeholder) - Battle and walking animations (There are no animations currently) - Evolution and Hatching animations - Story (There is no dialogue in the current build and I want to keep it mostly that way. So I will rely on environmental story-telling and puzzles to communicate the majority of the story. Even so I feel the need to add NPCs and dialogue) - Puzzles (There is a maze in the current build that will be improved but I don't consider that a "real" puzzle) - More platforming sections (The game isn't a platformer but people seem to enjoy the platforming sections) - Passive abilities that can be passed to offsprings through selective breeding - More monsters to catch - Optional bosses (Some of them will block the way to optional areas)” What is the current state of the Early Access version? “The game is playable the same way a demo is. Almost every feature is in but in a very rough state. The map is small and linear and some mechanics like enemies chasing you are barely functional. There are a lot of placeholder art left in the game and there are no animations. Every feature advertised in the game's description is present to some extent but needs to be polished.” Will the game be priced differently during and after Early Access? “The price will increase as features are added.” How are you planning on involving the Community in your development process? “I will address feedback as I see fit but I have a pretty clear vision. I read every review and watch every youtube video involving the game.
