Player is robot who want gold. So kill enemies in different levels and find gold treasure. Levels contain different enemies : flying and running goblins,  enemy bats and spike bosses in end of every levels. Also different traps like firespikes which will kill player. Player can also collect different weapons like spacerifle and firebomb weapons which is powerful weapon against bosses. Also health pick-ups are available. Game contains also checkpoint system where player will respawn after death. First version contains 9 levels and test level where player can check out different enemies, pick-ups and features. Robot player and enemies can also shoot through walls Features: - 9 levels - checkpoint system - Double-jump - Health system - Player sliding feature - Test level which show all important features of game -  3 different weapons: normal rifle, laser rifle and firebomb weapon - Ammo pick-ups - Health pick-ups - 4 different enemies: flying goblin, running goblin, bats, spike bosses with weapons - Camera shakes - Flying platformers - Super jump barrels - Controller/gamepad support Read manual file where is added gamepad and keyboard controllers System Requirements Minimum: OS *: windows xp Processor: 1.7+ GHz Memory: 1 GB RAM Graphics: 256 mb DirectX: Version 9.0 Storage: 400 MB available space Sound Card: Direct x9 Recommended: OS *: Windows 8 Processor: i5 Memory: 4 GB RAM Graphics: 256 mb DirectX: Version 9.0 Storage: 400 MB available space Sound Card: Direct x9 * Starting January 1st, 2024, the Steam Client will only support Windows 10 and later versions.
