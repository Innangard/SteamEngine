You can use a crosshair from the set of pre-built images, create your own in our image editor or crosshair generator, or choose one of the crosshairs created by our community. Features Rendering | HudSight can use the traditional technique using Hooks, as well as secure ways via Microsoft Game Bar extension or our Real Overlay technique. Generator | By adjusting various parameters in the crosshair generator you can quickly create your unique crosshair. Image Editor | The raster (pixel) editor allows you to draw any unusual crosshair. Images | Import any image from your disk to use as a crosshair. Workshop | Use crosshairs created by the Steam community, or share your own. Multi-crosshair | Use key bindings for quick switching between crosshairs or toggling crosshair visibility. Offset, scale, lean | Set the offset relative to the center of the screen, as well as the scale or tilt for each crosshair. Core feature of our software is a unique overlay rendering technique which is applicable both for full screen exclusive and windowed modes. Every gamer knows that playing in full screen mode offers maximum performance and minimal input lag. However, there is a problem with common "on top" overlay tools - they cannot work in the exclusive full screen mode. HudSight solves this problem by allowing you to add overlays even in full screen games! Moreover HudSight has special overlay rendering ability using its own Microsoft Game Bar extension. This is more safe technique in the case of games (anti-cheats) that are too afraid of hooks. Don't you like Game Bar? Use our Real Overlay mode to draw overlays "as Game Bar" but without Game Bar. HudSight supports games based on DirectX 9, 10, 11, 12, OpenGL and Vulkan graphics. 32 and 64-bits games are welcome on  Windows 10/11.
