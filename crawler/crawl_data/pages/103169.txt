Check out the full game View Community Hub About This Demo An incremental game about filling a canvas, then a bigger one, hiring painters to keep the page moving, and printing each finished page for a stronger start, all from a 1995 desktop. Cover the page Paint tiles for points, then spend them on a wider brush, a bucket, and tools that cover empty space for you. Grow the canvas Finish a page and the next one is larger, in a new color and pattern, until it no longer fits the window. Hire painters Automated painters hunt down leftover tiles and keep working while you are away. Print the page Send a finished canvas to the printer and start the next run stronger, with a better brush and painters already waiting.
