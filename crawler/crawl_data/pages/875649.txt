Standard Mode Start with Standard Mode if you need a simple auto clicker that’s quick to set up: Configure intervals between clicks, including random offsets Choose your mouse button type: left, right, middle, or side Use single, double, and hold clicks Specify a fixed number of clicks or run indefinitely Click at the current cursor location, fixed coordinates, or on detected images Advanced Mode For deeper customization, Advanced Mode provides a user-friendly, drag-and-drop interface to build complex automation sequences using different types of actions: Click Action: Perform specific clicks at chosen locations Scroll Action: Simulate mouse wheel scrolling Interval Action: Insert delays between actions Repeat Action: Loop actions multiple times or until stopped Detection Action: Search for images and branch your logic Key Action: Simulate keystrokes Random Action: Randomize your actions Custom Action: Group sets of actions for reuse and organization Recordings Record all clicks, keypresses, and delays, then replay or import them into custom actions for advanced routines.
