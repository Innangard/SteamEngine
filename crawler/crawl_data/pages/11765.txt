Remoção de dados Você é responsável por dados eventualmente armazenados no seu produto. Antes de enviar qualquer produto para reciclagem, você deve (a) excluir os dados em dispositivos de armazenamento (como discos rígidos) dos produtos; (b) realizar uma cópia de segurança ou transferir todos os dados antes da reciclagem; e (c) remover todas as mídias, como cartões microSD, CDs ou PC Cards. Também recomendamos que os consumidores usem programas de exclusão de dados para remover os dados dos seus produtos antes da reciclagem. A Valve não é responsável pela perda de dados resultantes da reciclagem do seu produto. Para excluir os dados do seu Steam Deck, siga os passos abaixo para formatar o dispositivo: Ligue o Steam Deck. Pressione o botão "Steam". Selecione "Configurações". Selecione "Sistema". Role até a seção de opções avançadas e pressione o botão "Formatar dispositivo". Confirme a seleção ao pressionar o botão "Formatar dispositivo" na janela pop-up.
