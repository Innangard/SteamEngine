Log Drop is a 2D physics automation game with one noble goal: get more logs into the earth's core than is physically reasonable. Chaotic or orderly, the contraption is yours. Fling, funnel and dam up the logs, then let the whole load go at once. Buy new tools as you go, and upgrade the ones you come to rely on. It's a sandbox. The core doesn't care how the logs get there. Features a campaign mode where every zone is its own puzzle, with its own objectives to complete. There will also be a sandbox mode with unrestricted access to tools so you can build whatever you want. Other Features to expect Multiple tree species requiring new tools to harvest and route to the core. Achievement based meta progression. Steam Achievements.
