View Community Hub About This Game Paver: Tidy Up Together is a satisfying first-person organizing game where you sort and place pavers to rebuild a plaza. Work at your own pace, follow the correct patterns, unlock useful skills, and watch a chaotic area gradually transform into a perfectly restored plaza. Game Modes Play solo or together in online co-op . Normal Mode : Progress normally and unlock new skills as you play. Sandbox Mode : Jump straight in with all the skills unlocked. No-Skill Mode : Challenge yourself with all skills disabled and complete the layout manually. Paver Layout Plan The restoration of the old castle is nearly complete—but the grand plaza is still unfinished. During the renovation, all pavers are mixed across the ground. Fortunately, you have the original paver layout plan . Your task is to place 4,064 pavers in the correct places. There are pavers with different colors, and also different shapes like rectangle, square, octagon, trapezoid, H-shaped, triangle, hexagon, trihex, and radial. Skills Highlighting Paver Layout: Highlights the correct place for the topmost paver in your hand Auto-Placement: Automatically places your pavers in the correct places Auto-Collect: Automatically collects the same pavers as the topmost paver in your hand System Requirements Minimum: Requires a 64-bit processor and operating system OS *: Windows 7 64-bit | Windows 8 64-bit | Windows 10 64-bit Processor: Intel Core i5-11400F | AMD Ryzen 5 5600x Memory: 8 GB RAM Graphics: NVIDIA GeForce GTX 1060 | AMD Radeon R9-290X Network: Broadband Internet connection Storage: 750 MB available space Recommended: Requires a 64-bit processor and operating system OS *: Windows 7 64-bit | Windows 8 64-bit | Windows 10 64-bit Processor: Intel Core i5-13400F | AMD Ryzen 5 7600x Memory: 8 GB RAM Graphics: NVIDIA GeForce GTX 1070 | AMD Radeon RX-6600 Network: Broadband Internet connection Storage: 750 MB available space * Starting January 1st, 2024, the Steam Client will only support Windows 10 and later versions.
